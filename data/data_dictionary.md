# Dataset Dictionary

| Column | Description |
|---|---|
| material_id | Unique identifier for the material |
| description | Raw material description |
| category_l1 | Level 1 category |
| category_l2 | Level 2 category |
| material | Main material composition |
| manufacturer | Manufacturer or brand |
| size | Physical size or dimension |
| standard | Industrial standard or specification |
| language | Main language of the description |
| noise_type | Type of text noise introduced |
| is_noisy | Whether the description contains synthetic noise |
